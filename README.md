# Умный офис

Учебный проект ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными интегрированными системами», МДК 03.01.
Специальность 09.02.08 «Интеллектуальные интегрированные системы», группа 54-15.

**Номер в журнале:** 20

## Назначение

Виртуальный прототип «умного офиса», показанный заказчику до развёртывания в реальном помещении:

- в серверной автоматически включается охлаждение при повышении температуры;
- сотрудник со своего рабочего места видит температуру, влажность, состояние вентилятора и историю измерений;
- при пропаже показаний датчика или недоступности приложения на CTRL администратору приходит письмо.

Датчики температуры (TEMP-01), влажности (HUM-01) и вентилятор (FAN-01) имитируются в Node-RED. Стенд собран в GNS3: коммутатор, маршрутизатор Cisco, четыре машины РЕД ОС 8 и одна Windows Server 2019.

## Схема обмена данными

```
IOT-01 (Node-RED)
  TEMP-01, HUM-01 каждые 5 с ──► CTRL-01 :8080 /api/readings
                              └─► DB-01   :8081 /api/readings  ──► SQLite
  FAN-01 ON / OFF ────────────► CTRL-01 :8080 /api/actuators
                              └─► DB-01   :8081 /api/actuators ──► SQLite

CTRL-01 :8080 /metrics ◄── Prometheus (MON-01, опрос каждые 5 с)
Prometheus ──► Grafana (панель, правила) ──► письмо на электронную почту
```

Логическая схема сети – `schemes/logical-topology.png`.

## Управление вентилятором

Каждое показание TEMP-01 проходит проверку: температура **выше 30 °C** включает FAN-01 (`ON`), **30 °C и ниже** выключает (`OFF`). Сигнал уходит на CTRL-01 и DB-01.

## Оповещения Grafana

Три правила в папке `office`, группа `office-alerts`, интервал оценки 10 секунд, ожидание Pending 0 секунд:

| Правило | Условие | Если данных нет |
|---|---|---|
| TEMP-01 нет новых показаний | возраст показания больше 20 с, пока CTRL доступен | Normal |
| HUM-01 нет новых показаний | то же для HUM-01 | Normal |
| CRTL недоступен | цель `up` меньше 1 | Alerting |

Письма уходят через контакт `email-admin` (SMTP-сервер и пароль приложения заданы в `/etc/grafana/grafana.ini` на MON-01 и в репозиторий не входят). Подробности – `monitoring/alert-rules.md`.

## Порядок запуска

Рабочие папки на ВМ: CTRL-01 – `/root/practice4/ctrl`, DB-01 – `~/practice6/db`, IOT-01 – `/home/student/practice4/iot`. Файлы из соответствующих папок репозитория копируются туда.

1. **DB-01:** `docker-compose -f compose.yml up -d`, проверка `curl -s http://127.0.0.1:8081/health`.
2. **CTRL-01:** `docker-compose -f compose.yml up -d`, проверка `curl -s http://127.0.0.1:8080/health` (в ответе `"version":3`).
3. **IOT-01:** контейнер Node-RED запускается автоматически (`docker ps`), иначе `docker-compose -f compose.yml up -d`. В редакторе должен быть загружен `flows.json`, оба узла `inject` включены, затем **Deploy**.
4. **MON-01:** службы запускаются автоматически, проверка `systemctl is-active prometheus grafana-server`.

## Проверка системы

1. Prometheus → Status → Targets: цель `office-controller` в состоянии **UP**.
2. Grafana: на панели видно «ДОСТУПНО», температуру, влажность, состояние вентилятора, возраст показаний менее 10 секунд; правила в состоянии **Normal**.
3. Node-RED, Debug: ответы приёмников `status: ok` и `status: stored`.
4. DB-01: число строк растёт, `sqlite3 data/telemetry.sqlite3 "SELECT COUNT(*) FROM measurements;"` (запрос повторить через 15 секунд).
5. История: http://192.168.20.13:8081/ показывает последние показания и сигналы FAN.
