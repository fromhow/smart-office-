# Умный офис

Учебный проект ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными интегрированными системами», МДК 03.01.
Специальность 09.02.08 «Интеллектуальные интегрированные системы», группа 54-15.

**Номер в журнале:** 20

## Цель проекта

Показать заказчику работающий виртуальный прототип «умного офиса» до развёртывания в реальном помещении:

- в серверной автоматически включается охлаждение при повышении температуры;
- сотрудник со своего рабочего места следит за состоянием оборудования и при необходимости управляет вентилятором вручную.

Показания датчиков температуры (TEMP) и влажности (HUM) и работа вентилятора (FAN, состояния `ON` / `OFF`) имитируются в Node-RED. Стенд собирается в GNS3: Cisco SW, Cisco RTR, четыре машины РЕД ОС 8 и одна Windows Server 2019.

## Роли устройств

| Устройство | Роль |
|---|---|
| WIN | Windows Server 2019, рабочее место администратора |
| CTRL | Управляющий узел (РЕД ОС 8): логика автоматического и ручного управления вентилятором, сбор файлов с других ВМ по SCP |
| MON | Узел мониторинга (РЕД ОС 8): отображение показаний датчиков и состояния вентилятора |
| DB | Узел базы данных (РЕД ОС 8): хранение измерений в SQLite |
| IOT | Узел с программными моделями (РЕД ОС 8): датчики TEMP, HUM и вентилятор FAN в Node-RED |

## Структура репозитория

- `README.md` — описание проекта
- `journal.md` — журнал работ по дням
- `.gitignore` — исключения (пароли, ключи, рабочий файл SQLite)
- `schemes/` — логическая схема сети (`logical-topology.drawio`)
- `docs/` — таблица адресации и портов (`addressing-table.xlsx`), черновик плана офиса
- `configs/` — настройки RTR и узлов
- `evidence/` — скриншоты проверок
